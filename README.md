# PC-Controller

Controlá el mouse y teclado de tu PC desde el celular por WiFi. Pensado para saltar intros/recaps de Netflix y otras plataformas.

## Descargar
La última versión está en la sección [Releases](https://github.com/FENCHI5/PC-Controller/releases/latest).

## Cómo funciona
- Instalás `PC-Controller-Setup.exe` en tu PC (Windows).
- El programa corre en la bandeja del sistema y te muestra la IP de tu PC.
- Desde el celular, en la misma red WiFi, te conectás a esa IP y controlás la PC.

> La PC y el celular deben estar en la misma red WiFi.
